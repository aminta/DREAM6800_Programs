DREAM 6800 · DREAMER programs

DREAMER programs for the DREAM 6800

The DREAM 6800 is a small Australian home computer by Michael J. Bauer, published as a build-it-yourself project in Electronics Australia in 1979: a Motorola 6800, 1 KB of RAM, a hex keypad, a TV output of 64×32 pixels and CHIPOS, a monitor with a CHIP-8 interpreter. Its users' newsletter, the DREAMER (1980-82), printed dozens of games as hex listings to type in. Here they are as ready-to-load files: 79 programs, each transcribed from the scans, checked and run in a simulation of the machine, together with the 6 programs Michael Bauer released on cassette with the machine (93 files in all).

Load them in the DREAM 6800 MiSTer core (OSD: Load program) or type them in on real hardware. CHIPOS and the machine's history: Michael Bauer's DREAM 6800 page.

Published with the blessing of Michael J. Bauer, the designer of the DREAM 6800, who in November 2026 placed the DREAM 6800 material in the public domain. Thank you, Michael!

File formats

  • .c8: CHIP-8 program, loads at 0200. Start it with C000 then FN 3.
  • .bin: 6800 machine code, loads and starts at 0200 (Dream Invaders).
  • .d68: for programs that load elsewhere (often 0080) or need more than 1 KB: 2 bytes load address, 2 bytes run address (big-endian), then the data. The MiSTer core starts it by itself.
  • Badges: 2K RAM needs the memory expansion; joystick needs Bauer's analog joystick (DREAMER no. 3), emulated by the core on the gamepad.

Screenshots come from the simulation. Every page lists the corrections applied to the printed listing (published errata, evidence in the article) and any doubt left. Found a mistake? Open an issue.

# TOWER OF HANOI
# K. Semrad, DREAMER 17 (Jan 1982), magazine page 10 (PDF page 19)
# CHIP-8, load 0200-0400, run C000 (FN 3)
# Transfer the seven discs from peg 1 to peg 2 or 3, one at a time, never a larger disc on a smaller one.
# First key pressed = FROM peg, second key = TO peg (keys 1, 2, 3; others ignored).
# At the end of the game press any key to restart.
# Behaviour (from the code): an illegal move (larger disc on smaller, empty FROM peg) shows "ERROR f ON t" and
# the next key restarts the whole game; the win screen shows the move count (3 digits) and "MOVE E".
# Doubt, left as printed: 03DE-03DF = 00 01 gives "MOVE E"; the font's char 7 (S, C546 at 03FC) is never
# used, so "MOVES" (07 at 03DE) was probably meant. Text font: 3x5 packed, 2 bytes/char from 03EE via CHIPOS C198.
# Correction: 0372 printed 0A35 (machine-code call to non-existent RAM); fixed to 6A35 = VA:=35, x of the third
# peg disc, by symmetry with 6A09 (peg 1, 0356) and 6A1F (peg 2, 036E); pegs are drawn at x 0A, 20, 36.
# Correction: 037E printed 00E0 (erase); fixed to 00EE (return): the disc-drawing subroutine 0376 must return
# when V0 (disc width) is 0 - empty slots; with 00E0 it clears the screen and loops forever.
# Machine code: 02F4-02FD (LDAA #20 / STAA 21 / LDAB #40 / JSR C2E5 / RTS), 038C-0393 (LDAA 30 / LDX #03EC / JMP C198).

# THREE IN A ROW
# K. Semrad, DREAMER 17 (Jan 1982), PDF page 54
# CHIP-8 + machine code, load 0200-0320 (printed 0200-0310), run C000
# A variation of 'Connect 4': get three marbles of your colour in a horizontal, vertical or diagonal row.
# Two players alternate (hollow / solid marble; the next player's marble is shown at the right).
# Keys 1-6 drop a marble in that column (full column: beep); other keys are ignored.
# After a win press C to restart.
# Machine code: 029C-0302 win check (board at 008C + 8*column + row, FF = empty, directions 1/7/8/9),

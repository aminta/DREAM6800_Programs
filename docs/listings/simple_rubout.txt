# SIMPLE RUBOUT - Bruce Mitchell
# DREAMER issue 6, magazine p.10 (PDF page 12). Load 0080-03FF (0100-01FF not printed: work area,
# filled with 00), CHIP-8 with subroutines at 0080-00FF, run C000.
# Two players take turns removing rectangles of dots: key two hex digits, first = horizontal side,
# second = vertical side of a rectangle whose top left corner is the flashing cursor. The area is
# shown, then the rectangle is erased dot by dot. Overlap (wrongly defined rectangle) = low beep and
# the other player gets two turns. 0 is not allowed (cancels a wrong first digit). Whoever removes
# the last dot wins.
# Corrections:
#  - 0202: printed 23CA (call 03CA = 16 random holes in the pattern); the article says first-time
#    users should replace it with A0FA ("eliminates the random holes"): applied (errata in DREAMER 6).
#  - 037E: printed 1540, crossed out by hand on the scan and corrected to 1550. It is the right end of
#    the first row of the "ALL GONE" end screen (rows copied from 0300 to display RAM 0170): with 1540
#    the right checkerboard misses one dot in its top row; 1550 matches 038E and 039E: applied.
# End screens: "ALL RUBBED OUT." then "ALL GONE" between two checkerboards.

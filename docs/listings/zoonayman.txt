# ZOONAYMAN - Lindsay B. Ford - DREAMER 11 pp.8-9 (PDF pages 10-11) - CHIP-8 0080-03FF (printed 0080-0400)
# run C000 (FN 3). Pattern-recognition game (idea: E.T.I. Aug 1978 p.74). The DREAM throws 50 dice and
# changes some of them by a non-random rule (at least 3 dice, else 'ERROR' and score +1, rethrow).
# You get 20 s to look (hold a key to shorten; data at 0301 = time in s, 3C = 60 s), then answer:
#   FROM = which dice value was changed (1-6), TO = changed to (1-6),
#   AT = where: 1 left, 2 right, 3 centre, 4 outside, 5 throughout.
# Each answer shows the correct one; score +1 right, -1 wrong. Win at 20, lose at 00.
# 0100-01C7 = preliminary title/scoring picture in the display buffer (shown while loaded from tape;
# erased by C000 FN 3). 0206 = 0000 is the hook for the TWO PLAYER SUBROUTINE (13FA, see zoonayman_2p.txt).
# Machine code: 03EE JSR C341 (CHIPOS LODUMX: display DMA off) RTS; 03F2 LDX #8012, LDAB #3F,
#   STAB 1,X (display on) RTS.
# 0306 EF9F is printed so and kept: not a standard op, but CHIPOS SKFKEY treats any EX9F like EXA1 when a
#   key is down and never skips with no key, so 6F0F EF9F = 'a key other than F is down' -> end viewing.
# Corrections: none (03F4 read 12C6 = LDAB #3F, the only sensible byte).

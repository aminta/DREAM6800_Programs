# FULLY AUTOMATIC FOUR WHEEL POKER MACHINE - J. Panos - DREAMER 12 p.14-15 (PDF p.16-17)
# load 0080-03FF (printed range 0080-0400); CHIP-8 starts at 0200, run C000 FN 3.
# 0100-01FF (display buffer) not printed. 0080-008B = reel positions / variables;
# 008C-00B0 symbols 9, 10, J, Q (6 rows, with tail), K, A, 7; 00B0-00FF CHIP-8 (symbol
# selection and reel tables).
# how to play: first set the 'bank': key a three digit decimal number (e.g. 0,5,2 = 52);
# you can only set it when it shows 000. C at any time resets the counter to zero.
# F spins the four reels; they stop one by one from left to right, about half a second
# apart. Each spin costs 1; winning lines add to the counter:
#   9,-,-,- 2   9,9,-,- 5 | 10,10,10,- / 10,10,A,- 10   10,10,10,10 50 | J,J,J,- / J,J,A,- 10
#   J,J,J,J / J,J,A,J 50 | Q,Q,Q,- / Q,Q,A,- 14   Q,Q,Q,Q / Q,Q,A,Q 50 | K,K,K,- / K,K,A,- 18
#   K,K,K,K / K,K,A,K 50 | A,A,A,- / -,A,A,A 120   A,A,A,A 1,000 | 7,7,7,- / -,7,7,7 120
#   7,7,7,7 1,000. A payout V9 is counted in by steps of 1 (VE = AA: steps of 10).
# With the counter at zero F does not spin.
# corrections (published by J. Panos in DREAMER 13 p.1 "AMENDMENTS", values checked on the
# scan of issue 13; the same two words are also corrected by hand on the issue 12 scan):
#   0332 30C6 -> 10C6  (the ACE on the 3rd wheel never showed up)
#   03EE 39C0 -> 39E0  (AAAA or 7777 added 240 instead of 1,000)
# DOUBT on the second amendment: A,A,A,A and 7,7,7,7 add 78 + 78 = F0 to V9 (03D8/03DC,
# 03E8/03EC: 7978 read zoomed, = the 120 of the pay table), so 03EE must test F0: with 39E0
# the counter still gets 240 (tests/four_wheel_poker_jackpot.txt); with 39F0 the jackpot
# (VE = AA, V9 = 64 -> 1,000) works. Kept 39E0 as published; 39F0 is the likely intent.
